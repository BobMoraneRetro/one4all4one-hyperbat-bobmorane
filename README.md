# one4all4one-hyperbat-bobmorane
Retrobat & Batocera Theme inspired from Hyperspin frontend

![LogoHyperbat](https://github.com/user-attachments/assets/526ea69f-a6c2-41bd-8864-e68552f1c745)

Theme for Emulation Station compatible with
- [Batocera](https://batocera.org/)
- [RetroBat](https://www.retrobat.org/)

** V 2.00 - (October 2026) **

Description :

    This theme is a standalone version of the Hyperbat view featured in the All4One4All multi-view theme.
    It's inspired by the Hyperspin frontend and allows you to assign a theme to each system or even each game.

---

# What's new in V2 (October 2026)

### New views
- **Game views**: FanartStar Boxart (very light), Retro Tower and Media tester (shows which media your scrape really contains), in addition to Hyperbat.
- **7 generic game themes** to choose from when a system has no dedicated theme: Standard, Standard without boxart animation, Standard with animated fanart background, Standard with back and front box, Arcade cabinet collection, Compact disc look.

### Much more content
- 186 dynamic system themes (79 in V1) and 936 generic system views (575 in V1).
- 46 dedicated default game themes, 3,514 system logos, 207 bezels, 1,689 system fanarts, styled letters for 30 systems.
- Game themes are now distributed through the **HyperBat Media showcase**, and can be installed straight from the RetroBat / Batocera interface.

### System view
- **System video frame**: keep the original bezel or use a rounded border that adapts to the video; combined with the plain system background you get a HyperSpin-like look.
- New presentation mode: *Dynamic HS, otherwise Unified HS* (default).
- New visual options: vignette, darker background, system list fade-out.
- Breadcrumb: can now be disabled.

### Game view
- **Game info style**: color, glow, font and size of the game name and info line, system by system.
- **2D or 3D box**, with scrape settings for where your 3D box and fanart are stored.
- Game theme source: original system folder, selected system folder, or generic views only.
- Default video for generic themes when a game has no screenshot or video.
- Game logo background: new "Disabled" and "unified size" choices.

### Screens and setup
- **4:3 and 16:10 screens** (experimental): 868 correction files keep video frames and spinning objects in shape.
- **Keep your custom themes safe**: 8 "Source" options let you relocate game themes, game media, system themes, bezels, publisher logos, fanarts, system logos and game info style to `themes/_bobmedia`, so updates never erase them.
- **14 built-in help boards** (English, and French for French users) in *Theme configuration › Welcome message*.
- Theme menu translated into **32 languages** (3 in V1), lighter compressed images.

# Tools to create game, system or default themes
Two free editors, available in the Tools category of the showcase:
- **HyperBat Theme Creator** by Dav: animations, shaders, rotations; generates the theme XML and images.
- **HyperBat** by Phenix: the most complete, with real-time preview; converts HyperSpin themes (.zip) one by one or in bulk. Video: https://youtu.be/BcYsYtOAP9M
